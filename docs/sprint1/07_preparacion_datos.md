# Preparación de acceso y uso de datos

Entregable S1-05: preparar procedimiento y solicitud. Esta entrega no envió solicitudes ni obtuvo permisos.

| Campo | Información a preparar |
|---|---|
| Solicitante | Integrantes, institución y contacto institucional verificado. |
| Finalidad | Investigación académica y apoyo a revisión humana. |
| Comunidades | r/Millennials y r/GenZ, sin atribuir edades reales. |
| Periodo | Fechas concretas dentro de 2025–2026, sujetas a autorización. |
| Operaciones | Obtención, conservación, anotación, entrenamiento, evaluación y difusión permitida. |
| Campos | Texto, comunidad, fecha, tipo, idioma y contexto mínimo. |
| Conservación | Fecha límite, ubicación autorizada, responsables y eliminación. |
| Difusión | Código, métricas y ejemplos modificados; sin datos restringidos. |
| Evidencia | Respuesta de autorización o licencia aplicable y condiciones verificadas. |

## Procedimiento

1. Identificar con proveedor e institución el mecanismo autorizado.
2. Preparar solicitud para revisión del equipo; tener PRAW o credenciales no acredita permiso.
3. Registrar respuesta y alcance antes de obtener datos.
4. Completar `../procedencia.example.json` con hechos y evidencia real.
5. Comprobar entrenamiento permitido, periodo, conservación y campos.
6. Ejecutar piloto únicamente bajo el mecanismo concedido.
7. Preparar y revisar corpus antes de anotar.

Si no se obtiene permiso, proponer corpus con licencia compatible y revisar delimitación. No presentar los ejemplos sintéticos como investigación sobre datos reales. La validación del manifiesto no concede derechos ni constituye revisión jurídica.
